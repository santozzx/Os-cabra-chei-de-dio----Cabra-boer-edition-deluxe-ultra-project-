# Casa da Cabra

Um cantinho para cuidar das cabras Boer: peso, saúde, alimentação, reprodução e genealogia, tudo no mesmo lugar.

## O que tem por aqui

- Plantel com cards das cabras Boer, busca e filtros.
- Ficha completa com pedigree, pesagens, saúde e premiações.
- Resumo da fazenda com números e gráficos.
- Controle de coberturas, partos e banco de sêmen.
- Guia com as características das cabras Boer.
- Imagens locais só de caprinos.

## Como rodar

O projeto agora está em **Next.js**.

```bash
npm install
npm run dev
```

Depois é só abrir [http://localhost:3000](http://localhost:3000).

Para gerar a versão final:

```bash
npm run build
npm run start
```

A tela continua com a mesma cara da Casa da Cabra, só que agora está organizada no Next e pronta para crescer sem ficar uma bagunça.
